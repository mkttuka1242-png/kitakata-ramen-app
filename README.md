# 喜多方ラーメン95

95店舗を探して訪問を記録する、HTML・CSS・JavaScriptの静的アプリです。診断・ルーレット・地図・SNS共有を含みます。

## 起動方法

1. VS Codeでこのフォルダを開きます。
2. Live Server拡張機能がある場合、index.htmlを右クリックして「Open with Live Server」を選びます。
3. 同じサーバーの /test-hours.html を開くと、日時を指定して本体の営業判定を確認できます。

ビルドやnpm installは不要です。file://での直接起動は、テストページのiframeアクセスや保存領域がHTTP起動と異なるため推奨しません。端末のタイムゾーンは日本（Asia/Tokyo）にしてください。祝日情報の取得には外部ネットワーク接続が必要です。

訪問記録はブラウザのlocalStorageに保存します。キーは kitakata-ramen-visited-v1 のままです。ホスト名・ポート・ブラウザが変わると別の保存領域になります。記録が見えない場合は、普段利用するURLとブラウザを確認してください。

## 営業判定の方針と理由

scheduleForDateが曜日・祝日・季節・振替定休日と営業時間を選び、hoursMatchが時刻範囲を判定し、shopHoursStatusが営業時間内（登録情報）・営業時間外（登録情報）・情報不足を返します。isOpenNowとdiagnosisShopStatusはこの共通処理を利用します。

- 開店時刻を含み、閉店時刻を含みません。昼休みなどカンマ区切りの複数時間帯を扱います。
- 深夜分は前日の営業枠から判定します。例えば月曜18:00–03:00の火曜02:00は月曜の営業枠です。火曜の夜営業から火曜未明の営業を推測しません。当日が定休日でも前日からの営業枠は継続する扱いです。
- 祝日情報がない年は通常日と断定できないため「要確認」とし、「営業時間内（登録情報）」から除外します。年をまたぐ深夜や振替判定には前日の年の情報も関係します。
- 本体は登録時間内なら定休日未登録でも目安として表示します。診断は従来の慎重な方針を維持し、定休日未登録を「要確認」として自動推薦から除外します。情報がないことを「定休日なし」と解釈しないためです。
- 日付だけの確認では当日の通常営業時間を案内し、時刻を指定した確認では前日からの深夜分も確認します。
- 冬時間は12–2月、冬季定休日は12–3月、春秋の週末時間は4–11月という既存の適用範囲を維持しています。
- 通常定休日でも祝日は営業、closedAfterHolidayがある店はその翌日を休業とする既存ルールを維持しています。この登録ルールが各店の最新情報と一致するかは別途確認が必要です。

実際の営業を保証するものではありません。臨時休業・売り切れ・営業時間変更は判定できません。

## 確認手順

本番の訪問記録を変更しないよう、検証用のローカルURLで行ってください。

1. 店舗をチェックし、再読み込み後も記録と制覇率が維持されることを確認。
2. 訪問済みで絞り込み、チェック解除後に店舗が消え、件数が減ることを確認。未訪問でも逆方向を確認。
3. 検索・地域・訪問状態を組み合わせ、全解除後も条件と件数が一致することを確認。
4. 診断で候補なしになった場合の「日時を選び直す」、坂内の近隣・ゆかりの案内を確認。
5. ルーレットの演出と再操作、地図、SNS共有画面への遷移を確認。実際の投稿は不要です。
6. 通信を遮断して再読み込みすると、祝日取得失敗と要確認表示になり、営業時間内（登録情報）の候補が除外されることを確認。通信を戻して再読み込みし、表示と絞り込みの更新を確認。
7. test-hours.htmlで開店直前・開店時刻・閉店時刻、昼休み、深夜0時以降、通常定休日、祝日、振替休業、冬季、第1曜日を確認。対象年の祝日情報がなければテストページは判定を停止します。
8. 保存データ破損の確認は検証用URLだけで行い、破損JSONや配列以外の値で再読み込みしても一覧が表示されることを確認。
